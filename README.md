# 💱 Currency Converter

A modern and lightweight **Currency Converter Web Application** that provides real-time exchange rates for over 150+ global currencies. Built with clean UI principles and optimized for a smooth user experience.

## 🚀 Overview

This project enables users to instantly convert currency values using live exchange rates fetched from a public API. It features a clean interface, dynamic UI updates, and a responsive layout suitable for all devices.

---

## ✨ Key Features

- 🌍 Supports **150+ international currencies**
- 🔄 Real-time exchange rates via API integration
- 🏳️ Dynamic country flags for selected currencies
- 🔁 One-click currency swap functionality
- 📱 Fully responsive design
- ⚡ Fast and lightweight
- 🎯 Default conversion: **USD → PKR**
